# Automated Hypothesis Validation with Agentic Sequential Falsifications (Popper)

Huang, Jin, et al., 2025 (first authors Kexin Huang and Ying Jin per the local LaTeX). arXiv 2502.09858. Read from local LaTeX: track_3/refs/Automated Hypothesis Validation with Agentic Sequential Falsifications (021method.tex, 030experiment.tex).

- Per-test evidence: each falsification test i yields a p-value p_i, converted to an e-value with the p-to-e calibrator e_i = kappa * p_i^(kappa-1), kappa in (0,1) (Eq. 1 in 021method.tex). The kappa value is not stated in the text I read; the worked example table (p=1.0 gives cumulative e=0.5; then p=8.8e-3 gives cumulative 2.67) is consistent with kappa = 0.5 (my back-calculation, not a stated value).
- Combination: E_i = product of e_s for s<=i (E_0=1). Reject the null / accept the hypothesis when E_i >= 1/alpha, else continue until the test budget N_max is exhausted. E is a non-negative supermartingale under the null, so Ville/optional-stopping gives P(E >= 1/alpha) <= alpha (Theorem 1, proved via Doob optional stopping in the appendix).
- Three assumptions are needed: (1) the null sub-hypothesis of each test is implied by the main null; (2) E[e_i | D_{i-1}] <= 1 under h_i^0, achieved by letting the design agent see only metadata, never the raw samples it will test on, and choosing each test before looking at its data; (3) the stop/continue decision depends only on data seen so far.
- Settings: nominal alpha = 0.1; at most 3 tests on DiscoveryBench and 5 on TargetVal; 5 independent runs; negatives made by column-wise permutation (Type-I error = fraction of rejects on negatives).
- Reported Type-I error (alpha=0.1): Popper 0.103 (sd 0.020) DiscoveryBench, 0.082 (0.046) TargetVal-IL2, 0.085 (0.028) TargetVal-IFNG. Power: 0.638, 0.580, 0.591. Uncontrolled baselines: CodeGen 0.145, CodeGen(o1) 0.248, Fisher combined test 0.311/0.264/0.173; removing the LLM relevance checker gives 0.134/0.340/0.300. Without sequential control, LLM agents inflate Type-I error.
- The relevance checker (LLM score R(h) in [0,1], discard if below threshold) is what keeps assumption (1) approximately true; ablating it is the largest Type-I inflation among Popper variants. Appendix lists p-hacking as a failure category.

Relevance to us: reuse e-value product with a fixed look budget (3 to 5) as the keep/discard gate for method changes, with each look run on a fresh, disjoint block of held-out origins and a valid p-value for "candidate beats incumbent on pinball loss". Caveat: the guarantee needs valid conditional p-values, which time-series loss differences only approximate (serial dependence).
